# Tag name is a unique natural key

A Tag's name is unique within its Project (ADR 0006): `UNIQUE (project_id, name)`, with a duplicate create reported as `409 Conflict`. External tooling — `growctl` manifests and the device simulator — identifies Tags by name within an explicitly selected Project. We chose this over letting manifests carry client-assigned Tag UUIDs because people and Devices naturally refer to process variables by name. Name lookup uses `GET /api/v0/projects/{project}/tags?name=`; an absent name returns an empty list. The UUID remains the internal identity used by PortBindings and REST resource paths. Older unscoped paths are compatibility aliases for the migrated Main project.
